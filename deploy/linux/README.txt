Feather для Linux (тестовая сборка, x86_64)

Подходит для EndeavourOS / Arch / Manjaro и других свежих дистрибутивов (нужна glibc 2.44+;
на Arch-подобных просто обновите систему: sudo pacman -Syu).

1. Распакуйте архив и выполните в папке:  ./install.sh
   Feather появится в меню приложений. Удаление: ./install.sh --remove
2. В поле «Адрес сервера» укажите адрес сервера сообщества (например, https://chat.example.com),
   нажмите «Регистрация» или «Войти».
3. Голос: зайдите в голосовой канал. Push-to-talk — шестерёнка внизу → «Push-to-talk»
   (в KDE клавишу назначают в открывшемся системном окне).

Настройки хранятся в ~/.config/feather, скачанные файлы — в «Загрузки/Feather».
