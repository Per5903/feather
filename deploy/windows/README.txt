Feather для Windows (тестовая сборка)

1. Распакуйте архив в любую папку и запустите feather.exe.
   Windows может предупредить «Неизвестный издатель» (программа ещё не подписана):
   «Подробнее» → «Выполнить в любом случае».
2. В поле «Адрес сервера» укажите адрес сервера сообщества (например, https://chat.example.com),
   нажмите «Регистрация» или «Войти».
3. Голос: зайдите в голосовой канал. Push-to-talk — шестерёнка внизу → «Push-to-talk» →
   «Назначить клавишу…» → нажмите клавишу или боковую кнопку мыши.

Настройки хранятся в %APPDATA%\Feather, скачанные файлы — в «Загрузки\Feather».
