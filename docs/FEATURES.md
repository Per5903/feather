# Что есть в Feather и чего пока нет

Обновлено: 2026-10-17. ✅ — работает и проверено (автотесты и/или вживую), 🟡 — работает частично или не проверено вживую, ❌ — нет.

## Аккаунты и вход

| | Статус | Комментарий |
|---|---|---|
| Регистрация и вход | ✅ | отдельный режим регистрации с повтором пароля |
| Регистрация по коду приглашения | ✅ | код сразу добавляет в сообщество |
| Режимы регистрации: открытая / по приглашению / закрытая | ✅ | в панели администратора или `FEATHER_REGISTRATION` |
| Сохранённый вход | ✅ | токен в системном хранилище ключей (KWallet, GNOME Keyring, диспетчер учётных данных Windows); нет хранилища — в файле |
| Отображаемое имя, аватар | ✅ | аватар 128×128, обрезка по центру |
| Смена пароля | ✅ | другие устройства выходят |
| Двухфакторная защита (TOTP, QR-код) | ✅ | Google Authenticator, Aegis, 2FAS… |
| Удаление аккаунта | ✅ | сообщения остаются от «Удалённого аккаунта» |
| Вход через другие сервисы (Google, Steam) | ❌ | |
