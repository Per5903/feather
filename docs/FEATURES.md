# Что есть в Feather и чего пока нет

Обновлено: 2026-10-11. ✅ — работает и проверено (автотесты и/или вживую), 🟡 — работает частично или не проверено вживую, ❌ — нет.

## Аккаунты и вход

| | Статус | Комментарий |
|---|---|---|
