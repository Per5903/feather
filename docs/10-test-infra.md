# 10. Серверы для тестов

## Коротко

| Этап | Где запускать | Стоимость |
|---|---|---|
| 0–1: прототипы и текстовое MVP | **Свой компьютер**, Docker на localhost | 0 |
| 2+: голос через интернет с друзьями | **Один VPS**: 2 vCPU, 4 ГБ RAM | недорогой тариф |
| Нагрузочные тесты | Мощный VPS с почасовой оплатой, на несколько часов | копейки за тест |

## Этапы 0–1: локально

Всё поднимается на своей машине через `docker compose`: `feather-server`, Postgres и LiveKit (`livekit-server --dev`).

- Два клиента можно запустить на одном компьютере или на двух компьютерах в одной домашней сети.
- Для локальной разработки достаточно 8 ГБ RAM (лучше 16).
- Чего локально **не проверить:** реальную задержку через интернет, прохождение через NAT у разных провайдеров и TURN. Для этого нужен VPS.

## Этап 2 и дальше: тестовый VPS

### Требования

| Параметр | Минимум | Зачем |
|---|---|---|
| CPU | 2 vCPU | LiveKit и сервер, до ~20–30 человек в голосе |
| RAM | 4 ГБ (2 ГБ впритык) | Postgres + сервер + LiveKit |
| Диск | 40 ГБ SSD/NVMe | ОС, база, загруженные файлы |
| Сеть | 100 Мбит/с, трафик без жёсткого лимита | Демонстрация экрана занимает 2–4 Мбит/с на каждого зрителя |
| IP | **Белый (публичный) IPv4** | Без него WebRTC и TURN не заработают |
| Виртуализация | **KVM** (не OpenVZ/LXC) | Нужен Docker |
| ОС | Ubuntu 24.04 LTS или Debian 12 | Стандарт, много инструкций |

### Порты (открыть в файрволе)

| Порт | Протокол | Для чего |
|---|---|---|
| 443 | TCP | HTTPS, API и WebSocket (через reverse proxy, например Caddy) |
| 7881 | TCP | LiveKit: WebRTC через TCP, если UDP недоступен |
| 3478 | UDP | LiveKit TURN |
| 50000–60000 | UDP | LiveKit: медиапотоки |

Нужен **домен** (подойдёт и бесплатный поддомен). Без HTTPS браузер не даст доступ к микрофону в веб-клиенте, а сертификат Let's Encrypt выдаётся только на домен.

### Где брать

- **Расположение** — ближе к тестерам. Если все из России, то дата-центр в Москве или Петербурге. Если тестеры из разных стран, то Финляндия, Нидерланды или Германия: туда хороший пинг из большей части Европы и России.
- С оплатой иностранных хостингов российской картой могут быть проблемы. Российские облачные провайдеры (Timeweb Cloud, Selectel, REG.RU и другие) принимают её без проблем. Конфигурация 2 vCPU / 4 ГБ обычно стоит порядка нескольких сотен рублей до ~1500 ₽ в месяц. Цены меняются, поэтому их нужно проверить перед покупкой.
- Перед покупкой уточните у провайдера, что **UDP не режется** и IP белый.

### Сколько выдержит такой сервер (ориентировочно)

Голос в Opus — около 40 кбит/с на поток. SFU пересылает каждому участнику потоки всех остальных:

- 10 человек в одном канале: 10 × 9 × 40 кбит/с ≈ **3,6 Мбит/с** суммарно. Это ничтожная нагрузка.
- 1 демонстрация экрана на 10 зрителей: ≈ **20–40 Мбит/с**.

Для закрытого теста с друзьями 2 vCPU / 4 ГБ хватит с большим запасом.

## Нагрузочные тесты (перед бетой)

- Голос: `lk load-test` (CLI LiveKit) имитирует десятки и сотни участников.
- Текст и Gateway: k6 или собственный бот-клиент на Rust из `crates/protocol`.
- Под тест арендуется мощный VPS с почасовой оплатой, после теста он удаляется.
- Задача теста — узнать, **сколько онлайн выдерживает минимальный VPS**. Эту цифру нужно указать в документации для админов.

## Домашний сервер вместо VPS

Это возможно (старый ПК плюс проброс портов на роутере), но часто провайдер не даёт белый IP (CGNAT), и тогда друзья не подключатся. Для тестов внутри домашней сети подходит, для тестов через интернет надёжнее VPS.
