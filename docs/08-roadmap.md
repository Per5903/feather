# 08. Дорожная карта

Сроки ориентировочные и рассчитаны на одного разработчика.

## Этап 0. Прототипы рисков (2–3 недели)

Цель — проверить, что выбранный стек выдерживает бюджет из [02](02-performance.md), **до того**, как писать продукт.

- [x] Пустое Tauri + SolidJS приложение: замер на Linux ([bench/README.md](../bench/README.md))
- [ ] То же на Windows (WebView2)
- [x] Виртуализированный список на 10 000 сообщений: ~200 DOM-узлов, +35 МБ к «полу» WebKit
- [ ] Плавность прокрутки на слабом железе
- [x] Голос через LiveKit Rust SDK: 5 участников + self-hosted LiveKit, задержка 39 мс, RAM 12 МБ
- [ ] Снизить CPU голоса с 8–9 % до < 2 %
- [x] Реальные микрофон и динамики (PlatformAudio), автоматический тест шумодава на виртуальном микрофоне
- [x] Аппаратное кодирование видео (NVENC/VA-API) через SDK, замер
- [ ] Настоящий захват экрана через портал (нужен пользователь)
- [x] Глобальный push-to-talk через портал: нажатие/отпускание работают (KDE 6.7)
- [ ] Push-to-talk поверх полноэкранной игры (проверка с пользователем)
- [x] Тот же экран на Slint, сравнительный замер ([bench/README.md](../bench/README.md))
- [x] **Решение:** переходим на Slint (D12 в [09-decisions](09-decisions.md))
- [x] Замер Slint на 2560×1440 → по умолчанию GPU-рендерер, программный как «экономный режим»

## Этап 1. Текстовое MVP (6–8 недель)

- [x] Монорепо, `deploy/docker-compose.yml`
- [ ] CI
- [x] `crates/protocol`: типы API и событий (JSON для REST, MessagePack для шлюза)
- [x] Сервер: регистрация, вход, сессии (непрозрачные токены, D16), выход
- [ ] 2FA (TOTP), список и завершение сессий
- [x] Серверы (гильдии), каналы, категории, инвайты (лимит использований, срок)
- [x] Gateway: HELLO, IDENTIFY, READY, HEARTBEAT, ленивые подписки, UNREAD_UPDATE
- [ ] Gateway: RESUME с буфером событий
- [x] Сообщения: отправка (nonce), история с пагинацией, редактирование, удаление, ответы
- [x] Токен LiveKit для входа в голосовой канал
- [x] Сквозной тест сервера на настоящем Postgres (`cargo test -p feather-server`)
- [ ] Роли, права, overwrites
- [ ] Файлы и превью картинок (WebP/AVIF)
- [ ] Реакции, упоминания, непрочитанные, typing
- [ ] UI: каркас в 3 колонки, тёмная тема, виртуализация
- [ ] Rust-ядро клиента: SQLite-кэш, переподключение
- [ ] Бенчмарк ресурсов в CI
